# Mariel Talisaysay — Portfolio

A responsive, static portfolio built with React, Vite, and Tailwind CSS. No backend or database is required.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The production website is generated in `dist/`.

## Update content

- Edit project descriptions, contributions, skills, and contact information in `src/main.jsx`.
- Each project has a clearly labeled image placeholder in `ProjectPlaceholder`. Replace it with an image when ready; preserve descriptive alt text.
- Adjust the white and soft-blue theme in `src/styles.css`.
- Replace `public/Mariel-Talisaysay-Resume.pdf` to update the downloadable resume.
- Contact uses email links and clipboard copying. Project buttons open accessible native dialogs.

Content is based on the supplied resume. No project repository or live-demo URLs have been invented.
